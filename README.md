# UT.urn
Android app implementing PodciniLib and processing YouTube contents, a companion service app to Podcini.A

Ensure compatibility with Podcini.A based on PodciniLib version.

## How to use

The app does not provide a UI feature. Its sole purpose is to assist Podcini.A in processing YouTube related feed or media. 
Once installed, without having to be launched, just ensure in Podcini.A-> Settings-> Network and Storage, enable "Use external apps". 
Then it will be automatically connected with Podcini.A and provide assistance upon request.
